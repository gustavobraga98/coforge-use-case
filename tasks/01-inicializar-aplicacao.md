# T1 — Inicializar a aplicação do mock

## Objetivo

Criar a estrutura executável do projeto e uma tela inicial vazia para o Atlas Travel.

## Escopo

- Configurar o framework e os comandos de desenvolvimento e build.
- Criar estilos globais mínimos e uma rota única para a demonstração.
- Definir uma estrutura clara para componentes, dados simulados e estilos.
- Documentar no README como executar o mock.

## Critérios de aceite

- O projeto inicia localmente com um único comando documentado.
- A tela inicial renderiza sem erros de console.
- Há uma estrutura clara para componentes, dados simulados e estilos.
- O README explica como executar o mock.

## Fora de escopo

Conteúdo final, integração externa, lógica de busca e persistência.

## Dependências

Nenhuma.
